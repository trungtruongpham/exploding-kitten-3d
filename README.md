# Mèo Bom (Fuse Cats)

A Vietnamese-first 3D online card game for 2 to 5 players, played in the browser, inspired by the "draw until someone explodes" mechanic.

- Design document: [docs/GAME_DESIGN.md](docs/GAME_DESIGN.md)
- 3D look-and-feel sample: [prototype/table-sample.html](prototype/table-sample.html) (open in a browser)

Status: design phase, no code yet.
